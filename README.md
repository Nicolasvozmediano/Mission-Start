# Mission-Start
Acabas de ser contratado como Desarrollador Junior en NextGen Web Solutions. Tu primera misión no es escribir código desde cero, sino preparar tu "estación de combate" digital y resolver un problema de rendimiento que está afectando a un cliente importante.  +1
🟦 MILESTONE 1 – Planificación y Preparación

🎯 Objetivo: Tener claro el alcance, métricas y herramientas antes de auditar
⏳ Duración estimada: 1 semana

Issues

Definir alcance del proyecto

Tipo: Task

Descripción: Determinar qué workspaces, usuarios y sistemas se auditarán.

Criterio de cierre: Documento de alcance aprobado.

Definir métricas de rendimiento

Tipo: Task

Métricas: tiempo de arranque, consumo CPU/RAM, estabilidad, errores, experiencia de usuario.

Criterio: Lista de KPIs documentada.

Seleccionar herramientas de auditoría

Tipo: Task

Ej.: monitores de rendimiento, logs, encuestas.

Criterio: Herramientas justificadas y listadas.

Crear Product Backlog inicial

Tipo: Task

Criterio: Backlog priorizado con historias técnicas.

🟦 MILESTONE 2 – Auditoría de Rendimiento

🎯 Objetivo: Obtener datos reales del estado actual
⏳ Duración: 1–2 semanas

Issues

Recopilar información técnica de los workspaces

Tipo: Task

Datos: hardware, SO, software, configuraciones.

Criterio: Inventario completo.

Medir rendimiento de los workspaces

Tipo: Task

Métricas reales registradas.

Criterio: Datos exportados y validados.

Analizar logs y errores frecuentes

Tipo: Bug / Task

Criterio: Lista de errores clasificados.

Entrevistar usuarios clave

Tipo: Task

Mínimo: 3 entrevistas.

Criterio: Resultados documentados.

🟦 MILESTONE 3 – Análisis y Diagnóstico

🎯 Objetivo: Detectar problemas y oportunidades de mejora
⏳ Duración: 1 semana

Issues

Identificar cuellos de botella

Tipo: Task

Criterio: Lista priorizada de problemas.

Comparar métricas con valores óptimos

Tipo: Task

Criterio: Tabla comparativa actual vs recomendado.

Evaluar impacto en productividad

Tipo: Task

Criterio: Conclusiones justificadas.

🟦 MILESTONE 4 – Estandarización del Workspace

🎯 Objetivo: Definir un modelo estándar óptimo
⏳ Duración: 1–2 semanas

Issues

Definir configuración estándar del workspace

Tipo: Task

Criterio: Documento técnico validado.

Definir buenas prácticas de uso

Tipo: Task

Criterio: Guía clara y comprensible.

Crear checklist de verificación

Tipo: Task

Criterio: Checklist reutilizable.

Proponer plan de adopción

Tipo: Task

Criterio: Pasos definidos y realistas.

🟦 MILESTONE 5 – Documentación y Entrega Final

🎯 Objetivo: Cerrar el proyecto con entregables claros
⏳ Duración: 1 semana

Issues

Redactar informe final de auditoría

Tipo: Task

Criterio: Informe completo y estructurado.

Preparar presentación ejecutiva

Tipo: Task

Criterio: Diapositivas claras para stakeholders.

Revisión final y correcciones

Tipo: Task

Criterio: Feedback aplicado.

Cierre del proyecto

Tipo: Task

Criterio: Milestones completados y aprobados
