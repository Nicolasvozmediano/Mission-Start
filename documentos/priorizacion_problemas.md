# Priorización de problemas – ASIR_Mission

## Criterios de priorización

Los problemas se priorizan según:
- Impacto en el rendimiento
- Impacto en la productividad
- Impacto en la experiencia de usuario
- Frecuencia del problema
## Problemas priorizados

| Prioridad | Problema | Impacto | Justificación |
|----------|---------|--------|--------------|
| 🔴 Alta | Uso excesivo de RAM | Alto | Provoca lentitud y cierres |
| 🔴 Alta | Errores recurrentes de aplicaciones | Alto | Interrumpen el trabajo |
| 🟠 Media | Arranque lento del sistema | Medio | Pérdida de tiempo diaria |
| 🟠 Media | Servicios innecesarios | Medio | Consumen recursos |
| 🟢 Baja | Errores DistributedCOM | Bajo | No afecta directamente |
## Problemas críticos

Los problemas críticos a abordar de forma prioritaria son:
- Uso excesivo de memoria RAM
- Errores recurrentes de aplicaciones
