# Checklist de verificación del workspace estándar
Proyecto: ASIR_Mission Start – NextGen Web Solutions

## 1. Datos generales
- [ ] Usuario asignado
- [ ] Fecha de revisión
- [ ] Tipo de revisión (Onboarding / Auditoría)

---

## 2. Hardware
- [ ] CPU mínima recomendada (≥ 4 núcleos)
- [ ] Memoria RAM mínima (≥ 16 GB)
- [ ] Almacenamiento SSD
- [ ] Espacio libre en disco ≥ 30 %

---

## 3. Sistema operativo
- [ ] Sistema operativo estándar instalado
- [ ] Sistema actualizado
- [ ] Parcheo de seguridad activo

---

## 4. Software base
- [ ] Navegador actualizado
- [ ] VS Code instalado
- [ ] Suite ofimática instalada
- [ ] Antivirus corporativo activo

---

## 5. Configuración del sistema
- [ ] Programas innecesarios deshabilitados en el arranque
- [ ] Servicios configurados correctamente
- [ ] Monitorización básica activa

---

## 6. Políticas de software
- [ ] Solo software autorizado instalado
- [ ] Versiones estables o LTS
- [ ] No se detecta software no permitido

---

## 7. Buenas prácticas de uso
- [ ] Escritorio organizado
- [ ] Archivos temporales eliminados
- [ ] Uso responsable de recursos

---

## 8. Resultado de la revisión
- [ ] Workspace conforme
- [ ] Workspace no conforme

Observaciones:
Checklist validado por el equipo del proyecto en entorno académico.
