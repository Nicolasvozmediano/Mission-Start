# Métricas de Rendimiento – Proyecto ASIR_Mission
1. Objetivo

Definir las métricas técnicas y de experiencia de usuario que se utilizarán para evaluar el rendimiento de los workspaces de NextGen Web Solutions.



2. Métricas Técnicas (KPIs)

2.1 Uso de CPU


Descripción: Porcentaje medio y picos de uso del procesador.

Unidad: %

Objetivo: No superar el 80 % de uso sostenido.


2.2 Uso de Memoria RAM


Descripción: Consumo medio de memoria durante la jornada laboral.

Unidad: GB / %

Objetivo: Mantener al menos un 20 % de memoria libre.


2.3 Tiempo de arranque del sistema


Descripción: Tiempo desde encendido hasta disponibilidad completa del workspace.

Unidad: Segundos

Objetivo: < 90 segundos.


2.4 Uso de almacenamiento


Descripción: Espacio libre disponible en disco.

Unidad: GB / %

Objetivo: > 25 % de espacio libre.


2.5 Estabilidad del sistema


Descripción: Número de errores críticos o reinicios inesperados.

Unidad: Nº de incidencias

Objetivo: 0 errores críticos.



3. Métricas de Experiencia de Usuario

3.1 Percepción de rendimiento


Descripción: Valoración del usuario sobre la velocidad del workspace.

Método: Encuesta

Escala: 1–5

Objetivo: ≥ 4


3.2 Frecuencia de bloqueos


Descripción: Número de bloqueos percibidos por el usuario.

Método: Encuesta / entrevistas

Objetivo: Mínimo o nulo.


3.3 Facilidad de uso


Descripción: Opinión del usuario sobre la fluidez del trabajo diario.

Método: Encuesta

Escala: 1–5



4. Medición y recopilación

Las métricas se recogerán mediante herramientas de monitorización del sistema, análisis de logs y encuestas a usuarios clave.



5. Validación

Las métricas definidas se consideran medibles, realistas y adecuadas para el análisis del rendimiento de los workspaces.
