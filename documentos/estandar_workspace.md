# Estándar de Workspace Corporativo
Proyecto: ASIR_Mission Start  
Empresa: NextGen Web Solutions  
Versión: 1.0  
Estado: Aprobado

---

## 1. Introducción

Este documento define el estándar de workspace corporativo aprobado para NextGen Web Solutions. Su objetivo es garantizar un entorno de trabajo homogéneo, estable y optimizado, facilitando el mantenimiento, reduciendo incidencias y mejorando la productividad de los usuarios.

---

## 2. Configuración técnica estándar

### 2.1 Hardware recomendado
- CPU: 4 núcleos mínimo
- Memoria RAM: 8 GB mínimo (16 GB recomendado)
- Almacenamiento: SSD 256 GB mínimo
- Conectividad: red corporativa estable

### 2.2 Sistema operativo
- Sistema operativo soportado y actualizado
- Actualizaciones automáticas habilitadas
- Antivirus corporativo activo

### 2.3 Configuración del sistema
- Inicio automático solo de software necesario
- Políticas de ahorro energético optimizadas
- Usuario sin privilegios de administrador

---

## 3. Software recomendado y permitido

### 3.1 Software base obligatorio
- Navegador web corporativo
- Herramientas ofimáticas
- Cliente VPN corporativo
- Software de seguridad

### 3.2 Software permitido
- Herramientas de desarrollo aprobadas
- Utilidades autorizadas por IT

### 3.3 Software no permitido
- Aplicaciones no licenciadas
- Software de alto consumo sin justificación
- Programas no aprobados por IT

---

## 4. Buenas prácticas de uso del workspace

- No instalar software sin autorización
- Mantener el sistema actualizado
- Cerrar aplicaciones no utilizadas
- Almacenar información en ubicaciones corporativas
- Reportar incidencias de forma temprana

---

## 6. Procedimiento de estandarización

1. Verificación inicial del workspace
2. Copia de seguridad de datos
3. Aplicación de configuración estándar
4. Instalación de software aprobado
5. Validación mediante checklist
6. Entrega al usuario

---

## 7. Aplicación del estándar

El estándar se aplicará:
- En nuevos workspaces
- En renovaciones de equipos
- De forma progresiva en entornos existentes
